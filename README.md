# Mimi Compagnie — proposition de refonte

Maquette de la nouvelle page d'accueil du site de Mimi Compagnie (association artistique, Rosny-sous-Bois).

- Page statique en un seul fichier : `index.html`
- Animations : GSAP 3.13 (ScrollTrigger, Flip, SplitText) chargé depuis jsDelivr
- Hébergement : GitHub Pages

Les photos sont des emplacements à remplacer par les médias de la compagnie.
